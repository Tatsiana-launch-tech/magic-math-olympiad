# 🛠️ Скилл: Создание интерактивных образовательных квизов

Этот скилл превращает Claude в ведущего архитектора по созданию детских образовательных квизов. ИИ ведет пользователя по четырехэтапному конвейеру: от сбора контента до публикации сайта на GitHub Pages.

## 🎯 Цель
Создать красочный, геймифицированный квиз с уровнями сложности, поддержкой персонажа-наставника и автоматическим подсчетом результатов.

## 📋 Алгоритм работы (Workflow)

### Этап 1: Сбор ингредиентов (Контент)
- **Задача:** Помочь пользователю структурировать базу заданий.
- **Требования:** 
    - Разбить задачи на 3 уровня: Лёгкий, Средний, Сложный.
    - Обеспечить разнообразие типов: Логика, Соотнесение, Выбор ответа, Загадки, Шарады, Кроссворды.
    - Проверить наличие четких ответов для каждого задания.
- **Результат:** Файл `base_tasks.md`.

### Этап 2: Чертеж (Дизайн и Сценарий)
- **Задача:** Создать визуальную и эмоциональную концепцию.
- **Требования:**
    - **Карта экранов:** Старт $\rightarrow$ Выбор сложности $\rightarrow$ Цикл заданий $\rightarrow$ Финал.
    - **Персонаж-наставник:** Разработать «Голос» персонажа (фразы приветствия, поддержки при ошибках и похвалы).
    - **Визуальный стиль:** Подобрать палитру цветов (градиенты для каждого уровня) и составить промпты для генерации графики в стиле Pixar/Disney 3D.
    - **Механики:** Описать техническую реализацию сложных типов заданий.
- **Результат:** Документ-концепция с картой и стилем.

### Этап 3: Магия кода (Разработка)
- **Задача:** Написать чистый, адаптивный код на HTML/CSS/JS.
- **Технические стандарты:**
    - **Единый файл:** Весь проект в `index.html`.
    - **UI/UX:** Использование `backdrop-filter: blur` для плашек, анимации левитации элементов, адаптивная верстка.
    - **Логика:** Один ответ на вопрос $\rightarrow$ реакция персонажа $\rightarrow$ переход к следующему заданию.
    - **Награды:** Система выдачи наград в зависимости от % успеха.
- **Результат:** Готовый файл `index.html` и папка `assets`.


### 💡 Золотые правила для ИИ
1. **Простота:** Объяснять технические моменты понятным языком.
2. **Пошаговость:** Не переходить к следующему этапу без подтверждения пользователя.
3. **Визуальность:** Предлагать конкретные HEX-коды и готовые промпты для нейросетей.
4. **Поддержка:** Вести пользователя дружелюбно и с юмором.

### 🚀 Запуск проекта

### Способ 1. Открыть HTML-файл

1. Скачайте проект на компьютер.
2. Убедитесь, что HTML-файл и папка `assets` находятся в одной папке проекта.
3. Откройте `index.html` двойным щелчком мыши.
4. Игра запустится в браузере.

Если файл называется не `index.html` (например, `index_logic_buttons.html`), можно переименовать его в `index.html` или открыть под текущим именем.

### Способ 2. Запустить локальный веб-сервер

Рекомендуется для локальной проверки перед публикацией.

1. Установите [Python](https://www.python.org/downloads/), если он ещё не установлен.
2. Откройте терминал или командную строку.
3. Перейдите в папку проекта:

   ```bash
   cd путь/к/папке/magic-math-olympiad
   ```

4. Запустите сервер:

   ```bash
   python -m http.server 8000
   ```

   В Windows можно использовать:

   ```bash
   py -m http.server 8000
   ```

5. Откройте в браузере адрес:

   ```text
   http://localhost:8000
   ```

6. Для остановки сервера нажмите `Ctrl + C` в окне терминала.

### 🧩 Категории заданий

| Категория | Действие игрока |
|---|---|
| Логика | Анализирует условие и выбирает один из трёх вариантов |
| Найди пару | Находит соответствующие друг другу элементы |
| Выбор ответа | Выбирает правильный вариант |
| Загадки | Разгадывает загадку |
| Шарады | Решает задание по подсказкам |
| Кроссворды | Заполняет словесную головоломку |

### 🛠 Технологии

- **HTML5** — структура игровых экранов.
- **CSS3** — стили и оформление интерфейса.
- **JavaScript** — логика игры, обработка ответов и переходы между экранами.

Для запуска не нужны сборка, установка зависимостей или отдельный backend.

### ✏️ Как добавлять задания на логику

Для задания типа `logic` используются три основных поля:

- `text` — условие задания;
- `options` — массив из трёх вариантов ответа;
- `correct` — правильный ответ, который должен точно совпадать с одним из элементов `options`.

Пример:

```javascript
{
  type: "logic",
  text: "Какой вариант правильный?",
  options: [
    "Первый вариант",
    "Второй вариант",
    "Третий вариант"
  ],
  correct: "Второй вариант"
}
```

После добавления задания проверьте, что в нём ровно три варианта, а значение `correct` полностью совпадает с текстом правильной кнопки.

### 🌐 Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html`, `README.md` и всю папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/(root)`
5. Нажмите **Save** и дождитесь публикации.
6. Откройте ссылку, которую GitHub Pages покажет в настройках.

После публикации проверьте стартовый экран, изображения, выбор уровня, выполнение заданий и итоговый экран.
