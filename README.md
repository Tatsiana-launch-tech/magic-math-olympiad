# 🪄 Школа Магии: Олимпиада по математике

Интерактивная математическая игра для детей. Игрок попадает в волшебную школу, выбирает уровень сложности, проходит задания разных типов и получает итоговый результат.

Проект создан на **HTML, CSS и JavaScript**. Он работает в браузере и не требует установки дополнительных библиотек.

## ✨ Возможности

- Три уровня сложности: лёгкий, средний и сложный.
- Шесть категорий заданий: логика, найди пару, выбор ответа, загадки, шарады и кроссворды.
- Интерактивное выполнение заданий и обработка ответов.
- В заданиях на логику — три варианта ответа в виде кнопок.
- Итоговый экран с результатом прохождения.
- Иллюстрации и игровые элементы, создающие атмосферу волшебной школы.

## 🎮 Пользовательский сценарий

1. **Старт.** Игрок открывает игру и видит стартовый экран «Школы Магии».
2. **Выбор уровня.** Игрок выбирает лёгкий, средний или сложный уровень.
3. **Прохождение олимпиады.** Игра последовательно показывает задания из разных категорий.
4. **Ответ на задание.** В зависимости от его типа игрок выбирает вариант, находит пару или решает головоломку.
5. **Переход дальше.** После выполнения задания игрок продолжает игру.
6. **Результат.** После прохождения всех заданий появляется итоговый экран.

## 🚀 Запуск проекта

### Способ 1. Открыть HTML-файл

1. Скачайте проект на компьютер.
2. Убедитесь, что HTML-файл и папка `assets` находятся в одной папке проекта.
3. Откройте `index.html` двойным щелчком мыши.
4. Игра запустится в браузере.

Если файл называется не `index.html` (например, `index_logic_buttons.html`), можно переименовать его в `index.html` или открыть под текущим именем.

### Способ 2. Запустить локальный веб-сервер

Рекомендуется для локальной проверки перед публикацией.

1. Установите [Python](https://www.python.org/downloads/), если он ещё не установлен.
2. Откройте терминал или командную строку.
3. Перейдите в папку проекта:

   ```bash
   cd путь/к/папке/magic-math-olympiad
   ```

4. Запустите сервер:

   ```bash
   python -m http.server 8000
   ```

   В Windows можно использовать:

   ```bash
   py -m http.server 8000
   ```

5. Откройте в браузере адрес:

   ```text
   http://localhost:8000
   ```

6. Для остановки сервера нажмите `Ctrl + C` в окне терминала.

## 🧩 Категории заданий

| Категория | Действие игрока |
|---|---|
| Логика | Анализирует условие и выбирает один из трёх вариантов |
| Найди пару | Находит соответствующие друг другу элементы |
| Выбор ответа | Выбирает правильный вариант |
| Загадки | Разгадывает загадку |
| Шарады | Решает задание по подсказкам |
| Кроссворды | Заполняет словесную головоломку |

## 🛠 Технологии

- **HTML5** — структура игровых экранов.
- **CSS3** — стили и оформление интерфейса.
- **JavaScript** — логика игры, обработка ответов и переходы между экранами.

Для запуска не нужны сборка, установка зависимостей или отдельный backend.

## ✏️ Как добавлять задания на логику

Для задания типа `logic` используются три основных поля:

- `text` — условие задания;
- `options` — массив из трёх вариантов ответа;
- `correct` — правильный ответ, который должен точно совпадать с одним из элементов `options`.

Пример:

```javascript
{
  type: "logic",
  text: "Какой вариант правильный?",
  options: [
    "Первый вариант",
    "Второй вариант",
    "Третий вариант"
  ],
  correct: "Второй вариант"
}
```

После добавления задания проверьте, что в нём ровно три варианта, а значение `correct` полностью совпадает с текстом правильной кнопки.

## 🌐 Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html`, `README.md` и всю папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/(root)`
5. Нажмите **Save** и дождитесь публикации.
6. Откройте ссылку, которую GitHub Pages покажет в настройках.

После публикации проверьте стартовый экран, изображения, выбор уровня, выполнение заданий и итоговый экран.
